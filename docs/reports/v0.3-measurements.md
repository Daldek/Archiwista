# Measurements and acceptance v0.3 "Actions" (plan A14)

**Date:** 2026-10-26. **Code:** Archiwista `feature/kartograf-data-output` (plan
`docs/plans/2026-10-25-archiwista-next.md`, Part 3, steps A1 to A14), Kartograf
`34fab30b` and IMGWTools `6bd35a49`, the pinned heads of their `feature/data-output`
branches (PROGRESS, Open questions). Data paths are written as `<data-dir>` (local disk)
and `<share>` (SMB share). The release 0.3.0 is the author's: nothing is tagged or
merged.

## 1. Conditions

- **Reference computer** (as in the [v0.2 report](v0.2-measurements.md), section 1):
  Intel Core i5-6400 (4 CPUs), 15.6 GiB RAM, Debian 13, Linux 6.12.94, the store on
  the SSD. The environment of the branch (`uv sync --locked --all-extras`): Python
  3.13.5, SQLite 3.46.1, FastAPI 0.144.0, Uvicorn 0.54.0, rasterio 1.5.2 (GDAL
  3.12.2), rio-tiler 9.0.6, pyproj 3.8.0, Playwright 1.64.0.
- **Preview fixtures** of v0.2 (`<data-dir>/previews-perf`, written next to the
  50,000-slot store by `tests.fixtures.preview_store`; the v0.2 report, section 1,
  describes them: 353 versions of ASC, SM5 JPEG and orthophoto sheets). They were
  written before step M2 of the plan, so their store had no marker
  `kartograf-store.json` and Archiwista refused it (`no_marker`). It was marked once
  with `kartograf store init --root <data-dir>/previews-perf/data`; the generator's
  only change since is that it marks the store it writes, so the marked copy is the
  one the generator writes today.
- **Method** (`tests/perf/test_warm_perf.py`): a real `archiwista serve` as its own
  process with an empty local preview cache and the setting `preview_warm_after_scan`
  on. Its scheduler's full scan at the start indexes the fixtures, and its next tick
  warms what the scan indexed in one `preview_warm` job. Then each of 40 sampled
  warmed versions is looked at once, as a person's first look: its description
  (`…/preview`) and the preview pane's thumbnail (`preview.png?size=512`), over HTTP
  with a session. p95 is the 38th of 40; job times are `finished_at − started_at`;
  `--no-cov`.

## 2. Criterion 8: the first thumbnail after pre-building (SSD)

| Operation | Target | Result | Assessment |
|---|---|---|---|
| scan of the preview fixtures at the start | (informational) | 1.4 s | — |
| the scheduler's warm-up of the scanned versions | (informational) | 94.9 s for 353 versions: 353 warmed, 296 of them waiting for a local COG (their thumbnail only, ADR-041), 0 failed, not stopped for lack of room | — |
| preview cache after the warm-up | below the limit | 40 MB | met |
| first description of a warmed version, `…/preview`, p95 | ≤ 200 ms | 4.2 ms (median 3.7 ms) | met |
| first pane thumbnail of a warmed version, p95 | ≤ 100 ms (a preview from the cache, SPEC 4.5; v0.2 decision 12) | 4.1 ms (median 3.6 ms) | met |

The thumbnail of a warmed version comes from the local preview cache (SPEC 4.6), so
the store's medium decides the warm-up's time, not the first look. The SMB variant of
the same test (`-m smb`, section 6) was not run: the share is the author's deliberate
scenario.

## 5. Limitations and open items

- **Live criteria (1, 2, 6)** are written as `tests/integration/test_live_actions.py`
  and not run: agents run no live tests (plan D10). An offline run with every
  connection refused reached the first network step of each of its three tests (the
  availability check, the project's download), so its set-up and the in-process and
  command-line calls before the network work.
- **Jobs panel** in the interface (plan A12): the downloads of the session run in the
  background with the top bar's "Pobieranie", their list, toasts and "Anuluj
  pobieranie" (ADR-043); the retry, the log and the other kinds of jobs are in the API
  and in `archiwista jobs`; criterion 5 is accepted through the API's retry.
- **Criterion 4 and the project card** (ADR-042 option I): an open question for the
  author.
- **SMB:** criterion 8 on the share (`-m smb`) is the author's deliberate scenario.
- **Area by unit name** (plan A15) waits for Kartograf's `find_admin_units` (KB-7);
  an area is chosen as in v0.1.
- **Untested in the browser:** a variant without a default format and a plan with
  conflicts (the stand-in producer has neither); the Kartograf lines of a real report
  are checked by the live test only.
