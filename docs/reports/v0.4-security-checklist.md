# v0.4 security checklist

Scope: the `feature/v0.4-team` server and the planned three-person LAN deployment. Requirements are from [OWASP ASVS 5.0.0](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/docs_en/OWASP_Application_Security_Verification_Standard_5.0.0_en.json). `Implemented` means the named code and existing tests cover the stated control, **not** that a live LAN security assessment passed. `Deviation` and `pending` are release-review items. The T12 browser scenario uses a local test CA; the physical three-computer/SMB exercise is the author's runbook, not yet observed.
